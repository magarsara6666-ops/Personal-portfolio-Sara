# MAGARSARA Freelance Digital Marketing

A responsive personal landing page for MAGARSARA, a freelance digital marketing service based in Nepal.

## Highlights

- Brand strategy, social media, paid campaigns, content, SEO, and landing-page services
- Personal freelance positioning and a clear email enquiry path
- Responsive burgundy-and-blush presentation with the MAGARSARA neon brand mark
- Built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Quality checks

```bash
npm run typecheck
npm run build
```
